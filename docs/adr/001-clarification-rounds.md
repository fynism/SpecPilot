# ADR 001：跨轮总览与按轮澄清

状态：已采纳。日期：2026-10-13。

## 背景

单题澄清工具在 Agent Loop 内等待答案，用户无法查看尚未处理的需求主题，也不能自由选择
回答顺序。一次生成固定问卷又无法适应用户回答带来的分支和新约束。

## 决定

保留 ReAct 工具循环，在澄清能力中增加版本化总览和每轮问题。模型调查后通过受控发布工具
返回用户界面；用户编辑草稿，按轮提交后再运行模型。总览允许动态增补，不宣称穷尽所有问题。
使用现有 Registry／Executor／Hook、Spec 操作和单进程 Session，不引入多 Agent 或调度框架。

Spec 是需求事实源，Session 保存交互与草稿。宿主为真实提交创建不可改写证据；模型的解决
建议经来源和引用校验。修改回答使关联事项复核，旧问题版本、答案和决策可追溯。

## 替代方案与后果

- 固定问卷：实现简单，但条件分支容易过期，也会制造不必要问题。
- 每题即时运行：追问及时，但清单可能在用户填写时变化，模型调用与一致性成本更高。
- 按轮提交：填写期间稳定，用户可掌握全局；追问延迟到下一轮，需明确展示待细化项与变更摘要。

Session 升级为 v2 并备份 v1；仍只提供轮次间恢复。无进度的继续被拒绝，阻塞项未决时不能
进入待批准状态。真实模型质量与成本依据独立 Eval 比较，不以增加提问数量作为成功证据。
